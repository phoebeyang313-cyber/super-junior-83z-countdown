# SUPER JUNIOR 83Z Countdown

A static countdown page for the Macau stop of the 2026 FANCON TOUR [1983].

## Preview locally

Open the page directly in a browser, or run:

```bash
cd /workspaces/super-junior-83z-countdown
python3 -m http.server 8000
```

Then visit:

http://localhost:8000

## Deploy publicly

This page is a static HTML file, so the easiest free option is GitHub Pages.

1. Push this repo to GitHub.
2. Open the repo in GitHub.
3. Go to Settings -> Pages.
4. Set Source to "Deploy from a branch".
5. Choose the main branch and the root folder.
6. Save.
7. GitHub will generate a public URL like:
   `https://your-username.github.io/super-junior-83z-countdown/`

You can also use Vercel or Netlify if you prefer a drag-and-drop deployment.

The page itself is already ready for public hosting because it only uses HTML, CSS, and JavaScript.
